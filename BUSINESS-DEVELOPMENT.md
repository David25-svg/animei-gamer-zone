# AGZ Business Development System

## Funnel
Target account → Outreach → Website → Event Support Inquiry → Meeting → Qualified → Proposal → Negotiation → Won/Lost.

## Target buyers
Game publishers, game studios, agencies, overseas exhibitors and teams attending U.S. gaming conventions.

## Weekly operating rhythm
1. Build a list of exhibitors for upcoming target events.
2. Prioritize companies likely to need U.S. staffing, hardware, print, furniture, logistics or playtesting.
3. Send short personalized outreach and link to the most relevant AGZ page.
4. Log every qualified lead and the next action.
5. Follow up until a clear yes/no/next date.
6. Track meetings, proposals, close rate and won revenue.

## Pipeline stages
New Lead → Contacted → Meeting → Qualified → Proposal Sent → Negotiation → Won / Lost

## KPIs
Qualified leads/month; meetings/month; proposal rate; close rate; average project value; won revenue; lead source.

IMPORTANT: Keep the populated lead tracker private. Do not commit customer/contact data to a public GitHub repository.
